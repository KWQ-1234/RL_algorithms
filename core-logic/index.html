RL 算法的核心逻辑：从不动点 $\pi^*$ 到两层坐标与受控验证

在模型自己的输出上，按奖励重新加权，每次只挪一小步。目标层（A）决定不动点 $\pi^*$ 在哪（决定上限）；逼近层（C，仅在离策略区间 B 生效）决定怎么稳定高效地到达 $\pi^*$。

问 1 · RL 算法的核心逻辑是什么

三层：目标、目标解、逼近方式

第一层在优化什么

$$J(\theta)=\mathbb{E}_{x\sim D,\;y\sim\pi_\theta(\cdot|x)}\big[R(x,y)\big]$$

它和监督学习有两个本质区别：

  1. 数据分布依赖于参数本身。样本 $y$ 由 $\pi_\theta$ 生成，参数一变，数据也变。
  2. 奖励是黑箱。$R$ 对 $y$ 不可导，梯度只能借助 log-derivative trick 求：
$$\nabla J=\mathbb{E}\big[R(x,y)\,\nabla\log\pi_\theta(y|x)\big]$$

这就是 REINFORCE。换个角度看，它是在自己采出的样本上做加权 SFT，权重是奖励。所有 RL 算法都从这个式子出发。

第二层目标解是什么样

加上“不要偏离参考模型太远”的约束：

$$\max_\pi\;\mathbb{E}_\pi[R]-\beta\,\mathrm{KL}(\pi\,\|\,\pi_{\text{ref}})$$

它有闭式解：

$$\pi^*(y|x)\;\propto\;\pi_{\text{ref}}(y|x)\,\exp\!\big(R(x,y)/\beta\big)$$

也就是把参考分布按奖励做指数倾斜。这个式子决定了 RL 能做什么、不能做什么：

  • 它只能重新分配已有的概率质量。$\pi_{\text{ref}}$ 给零概率的回答，乘以多大的系数仍然是零。所以 RL 主要是在 base model 的支撑集内锐化，覆盖率主要由预训练决定。
  • $\beta\to 0$ 时，质量全部集中到奖励最高的回答上。这就是 sharpening：pass@1 上升，多样性和大 k 下的覆盖率下降。
  • $R$ 只是代理目标。倾斜得越狠，越会放大 $R$ 本身的错误，也就是 reward hacking。KL 项的作用就是限制倾斜的程度。

不同算法只是逼近 $\pi^*$ 的不同方式：

方式代表
迭代地采样、打分、做梯度步PPO、GRPO
用偏好对直接拟合闭式解DPO
采 n 个只留好的，再做 SFTrejection sampling、RAFT
让老师直接给出目标分布on-policy distillation

第三层怎么用有限样本逼近

$\pi^*$ 没法直接采样，于是只能迭代：

$$\pi_{k+1}\;\propto\;\pi_k\,\exp\!\big(\hat A/\tau\big)$$

每一轮从当前策略采样，估计每个回答比平均好多少（advantage），据此把概率往好的方向挪一小步。这就是 mirror descent，Kimi k1.5 就是按这个框架写的。PPO 的 clip 和 TRPO 的 KL 约束都是在近似“挪一小步”。

照着这个式子实际去做，只会遇到三个根本困难，几乎每个算法改动都是在处理其中之一：

  1. 方差大（credit assignment）。一条几千 token 的回答只有一个标量奖励，估计非常吵。对策是减去 baseline，引入 critic 或 group mean，再做归一化。减 baseline 不引入偏差，因为 $\mathbb{E}[\nabla\log\pi]=0$。
  2. 数据不是当前策略采的（off-policy）。原因包括同一批数据更新多步、异步 rollout、推理引擎和训练引擎的数值不一致。要用这些数据就得乘 importance ratio，而 ratio 的方差会爆炸，所以才需要 clip、截断、masking，也就是 trust region。
  3. 奖励不可信，或者探索不够。代理奖励会被钻空子，所以需要 KL 约束、可靠的 verifier，以及不能被优化器利用的奖励形式。另外，策略只能强化自己采得到的东西，没采到的永远学不会。

小结：三个选择

  • 数据从哪来：on-policy 的程度有多高。
  • 每个样本给多大权重：奖励和 advantage 怎么算。
  • 每步走多远：trust region 怎么设。

上限由 base model 和奖励质量决定，算法主要决定能否稳定、高效地逼近这个上限。

问 2 · 怎么给成千上万的算法建立坐标体系

从“三个选择”扩成“五轴索引”，再升级为区分“去哪”与“怎么去”的两层坐标（A / B / C / D）

第一步：为什么问 1 的“三个选择”不够，按代码模块会扩成五个轴？

问 1 结尾的“三个选择”（数据从哪来、每个样本给多大权重、每步走多远）只覆盖一大类算法：单轮生成、标量奖励、用 policy gradient 优化期望奖励。PPO、GRPO、DAPO、GSPO、CISPO、RLOO、REINFORCE++ 和各种 off-policy 修正都在这个框里，2025 年以来的大部分命名算法也属于这一类。

但放眼整个 post-training 文献，有五类工作放不进“三个选择”里，原因各不相同：

  1. 目标本身不是“期望奖励 + KL”。 pass@k 训练优化的是 $\sum_x \big(1-(1-p_x)^k\big)$，MaxRL 近似优化 $\sum_x\log p_x$，两者都不是期望奖励的简单线性平均。SPPO、Nash-MD 处理可能不传递的偏好，目标是一个博弈的 Nash 均衡。
  2. 奖励从哪来，本身是一个独立的设计维度。 PRM、rubric/judge、self-certainty、熵最小化、TTRL 的多数投票、on-policy distillation 里老师的 log 概率，改的都是监督信号，不是估计量。把它塞进“怎么加权”粒度太粗。
  3. 不走 policy gradient 的估计路线。 ILQL、soft Q-learning 这类 value-based 方法先学 Q 再导出策略；DPO 系直接拟合闭式解；RAFT、ReST 用过滤后的 SFT。它们和 PPO 逼近的可能是同一个目标分布，但具体更新方式不同。
  4. 多轮、有状态的 credit assignment。 agent 任务里有环境状态和工具输出，turn-level advantage、GiGPO 的状态分组、环境 token 屏蔽，都是单轮 bandit 视角里不存在的维度。
  5. 采样分布的设计远不止 on/off-policy。 选哪些 prompt（难度过滤、课程）、从哪个前缀分叉（TreeRL、在 entropy 高的位置分支）、用什么温度。

为了把这些工作都装进来，最直观的做法是按“一篇论文改了代码里的哪个模块”，把“三个选择”扩成五个并列的轴：

  • 目标Objective逼近哪个分布或解。期望奖励、pass@k、log-likelihood、风险敏感目标；正则项（KL 方向、强度、参考策略固定还是滚动更新）；或者一个博弈均衡、一个老师分布。
  • 信号Signal奖励从哪来。规则 verifier、学习得到的 RM、PRM、judge/rubric、偏好对、内在信号、老师的 log 概率。
  • 数据Sampling样本怎么来。离线、在线或延迟；选哪些 prompt、怎么分叉、温度、过滤。
  • 估计量Estimator怎么把信号变成更新。policy gradient（baseline、归一化、credit 粒度、聚合方式）、闭式拟合（DPO 系）、过滤 SFT、value-based。
  • 更新控制Update control每步走多远。clip、IS 截断或屏蔽、近端 KL、每批数据更新几步。

第二步：为什么平铺的五轴还不够？——五轴不是平等的，而是两层

上面这五个轴适合用来索引一篇论文改了哪里，但它把五个轴并列成了平等的维度，丢掉了 RL 算法里最重要的因果结构：哪些轴决定“去哪”，哪些轴只决定“怎么去”。

回到问 1 第二层的式子 $\pi^*(y|x) \propto \pi_{\text{ref}}(y|x)\exp(R(x,y)/\beta)$：

  • 目标层：决定不动点（或最优解集）$\pi^*$ 在哪。 对应五轴里的“目标”和“信号”，再加上 base model（$\pi_{\text{ref}}$）。它们决定渐近上限，也决定模型会被钻什么空子。
  • 逼近层：决定能不能稳定、高效地到达 $\pi^*$。 对应五轴里的“数据”、“估计量”、“更新控制”。在动力学稳定区内，它们主要影响偏差、方差、速度和稳定性。

两个必须交代清楚的理论细节（$\beta=0$ 退化与跨题权衡）：

  1. 当 $\beta = 0$（主流数学/代码 RLVR 设置）时，$\pi^*$ 从唯一点退化为单纯形面： 当 $\beta > 0$ 时，$\pi^*$ 是由目标层唯一确定的内点分布；但在 DAPO、Dr. GRPO、GSPO、ScaleRL 等现代 RLVR 配方中，显式 KL 常被设为 $\beta = 0$。此时对任意 $R(x,y)\in\{0,1\}$，所有将概率 100% 放在正确回答子集 $\mathcal{Y}^+(x)$ 上的分布（$p_x=1$）都是全局最优解——$\pi^*$ 不再是一个点，而是一个单纯形面 $\Delta(\mathcal{Y}^+(x))$。在这个单纯形面上，算法最终停在哪一个具体模式（是坍缩到单一短套路，还是保留多条推理路径），直接由逼近层 C 从 $\pi_{\text{ref}}$ 出发的隐式镜像下降轨迹决定。
  2. 跨题加权 $F(p_x)$（A2）在 $\beta>0$ 与 $\beta=0$ 下的物理含义不同： 如果每道题独立优化且 $\beta=0$，任何严格递增的 $F(p_x)$（无论是 $\sum p_x$、$\sum 2\arcsin\sqrt{p_x}$ 还是 $\sum\log p_x$）的单题无约束极值都是 $p_x=1$。$F'(p_x)=w(p_x)p_x(1-p_x)$ 真正改变的是：① 在 $\beta>0$ 时把每道题的有效正则温度改成了 $\beta_{\text{eff}}(x)=\beta/w(p_x)$；② 在 $\beta=0$ 但模型参数共享、训练步数有限时，改变了简单题与难题之间的梯度分配流速比（跨题轨迹权衡）。

所以真正有判别力的问题不是“它改了五轴里的哪一轴”，而是：这个改动有没有改变目标层（不动点 $\pi^*$ 或跨题目标权重 $F(p_x)$）？
• 没改变：属于逼近层改动。在未触发崩溃相变的稳定区内，它的增益应该体现在收敛速度或吞吐效率上，而不是渐近上限上。
• 改变了：属于目标层改动，往往伪装成逼近层的技巧。这类改动最值得警惕，也最常被误读。

伪装成逼近技巧的目标改动

平铺的五轴把下面这些操作都归到“估计量”、“更新控制”或“数据”，但按两层检验一看，它们的性质完全不同：

改动在五轴里看起来在改实际上（按两层结构检验）
GRPO 除以组内 std $\sigma_G$估计量 降方差改了目标层（A2）：把跨题目标从 $\sum_x p_x$ 换成 $\sum_x 2\arcsin\sqrt{p_x}$，放大 $p_x \to 1$ 与 $p_x \to 0$ 两端的梯度权重
Token 级 vs. 序列级 $\frac{1}{|y_i|}$ 聚合估计量 求平均方式改了目标层（A3）：按长度给回答重新加权，等价于换了目标分布
$k_3$ KL 估计直接放进 loss 求导正则实现 低方差 KL改了目标层（A4）：梯度有偏 $-\beta(\frac{\pi_{\text{ref}}}{\pi_\theta}-1)\nabla\log\pi_\theta$，不动点不再是反向 KL 的解
Clip 上下界不对称（Clip-Higher）更新控制 调截断超参有偏的更新（动力学 D1）：在 $\mu>1$ 时引入正样本漂移偏置，系统性地改变策略熵的走向
PPO-clip / CISPO / GSPO（完全 on-policy）更新控制 新代理损失什么都没改（$\text{B1}=\text{on-policy} \implies \text{C1}=\varnothing$）：$r\equiv 1$，梯度完全等于 REINFORCE
Dynamic sampling（过滤 $p_x \in \{0,1\}$ 题）数据 改变采样分布不改目标方向（纯省算力 D2）：$p_x \in \{0,1\}$ 的题本来就没有梯度（$\hat A \equiv 0$），过滤只省了反向传播算力

平铺的五轴还漏了三样东西

  1. base model（$\pi_{\text{ref}}$）不在任何一轴上，但它是最重要的坐标。 支撑集由它决定（见问 1 演示中的 y9），同一个算法在 Qwen 和 Llama 上的结论可以完全相反（spurious reward 就是典型例子）。它不属于算法，但属于问题本身的给定条件（Cond），分类和预测时必须标出来。
  2. 轴与轴不正交。 归一化在“估计量”里实现，作用却落在“目标”上；off-policy 修正（“更新控制”）只有在数据陈旧（“数据”轴 $\mu>1$ 或引擎不一致）时才有意义，严格 on-policy 时根本不工作；PRM 和 OPD 改了“信号”，也就同时改了目标分布。
  3. 动力学相变边界（探索与可达集坍缩）。 RL 的采样分布来自 $\pi_k$ 本身，这是一个反馈回路。在平滑稳定区内，逼近层 C 只影响收敛速度；但一旦 C 层的选择跨过了某个动力学崩塌阈值（如第四象限 Q-IV 负梯度打穿公共前缀、MoE 路由翻转失控、或截断长度小于解题所需最短长度 $L_{\text{cap}} < T^*(x)$），就会引发不可逆的熵坍缩或前缀损坏，直接把可达上限砸穿。静态的五轴描述不了这种分段相变。

第三步：把五轴重构为两层 `ABCD` 坐标体系

如果我们不仅想给论文归档，还想用尽量少的坐标去解释和预测“为什么同坐标算法在受控实验中往往打平，异坐标算法在什么条件下拉开差距”，坐标设计就必须满足四个条件：

  1. 按算法实际计算的规范方程定坐标，不按机制或名字。 CISPO 和 GSPO 机制不同，但严格 on-policy 时梯度完全一样，必须落在同一格；反过来，GRPO 和 Dr. GRPO 只差一个除以 std，但目标不同（arcsin 对 linear），必须分到两格。做法是把每个算法写成规范形式，直接从式子里读坐标：
    $$g(\theta)=\sum_x \underbrace{w(p_x)}_{\text{A2}}\sum_{i,t} \underbrace{c_{i,t}}_{\text{A3}}\,\underbrace{\psi(r_{i,t},\hat A_{i,t})}_{\text{C1, C2（仅在 B1 非 on-policy 时展开）}}\,\nabla_\theta\log\pi_\theta(y_{i,t}\mid x,y_{i,<t}) - \underbrace{\beta\,\nabla_\theta\widehat{\mathrm{KL}}(\pi_\theta, \pi_{\text{ref}})}_{\text{A4}}$$
  2. 坐标必须带运行区间（`B1`）。 等价关系是有条件的：$\mu=1$、$\pi_{\text{old}}$ 在训练端重算时，所有 clip 变体严格等价；一批数据更新十几步、跑 MoE、有异步延迟时，它们才分开。所以逼近层的 ratio 控制（`C1`）只在 off-policy 区间里才有取值，在 on-policy 区间里它是空的（$\varnothing$）。
  3. 格子的粒度由评测噪声底（MDE）决定。 “效果差不多”要有统计尺度。单 seed、AIME 30 题、$k=32$ 时，两个分数之差的 95% 最小可检测效应（MDE）大约是 $\pm 4.6$ 分（500 题 MATH 约为 $\pm 1.5$ 分）。没有受控证据显示差异超过这个尺度的两个取值，就合并成一格。理论给出哪些严格等价，证据决定哪些区别值得保留。
  4. 实验条件（`Cond`）不是算法坐标，但预测必须以它为条件。 base model、数据难度分布 $P(p_x)$、算力预算不属于算法，却会和坐标发生交互（例如 $F(p_x)$ 的选择只有在数据里有很多 $p_x$ 接近 $0$ 或 $1$ 的题时才起作用）。所以能承诺的是“同坐标、同条件下效果相近”。

D. 推导量
（由 A–C 推出的自检预测）		D1–D2D1 熵漂移方向 $\Delta\mathcal{H}(\pi_k)$（检验逼近层是否通过早熟熵坍缩改变了哪些答案还采得到）/ D2 样本效率（有效非零梯度样本占比）

从这张表可以读出两条分段可证伪的预测规则：
1. 在动力学稳定区内，A 相同则上限应该相近；但 C 层决定了稳定区的相变边界。 在相同条件 Cond 下，只要 C 层没有越过崩溃阈值（如 Q-IV 负梯度打穿公共前缀、MoE 路由翻转失控、或截断长度 $L_{\text{cap}} < T^*(x)$），C 层只影响收敛速度，上限由 A 层决定；一旦 C 层越过相变边界触发 D1 可达集坍缩，上限会直接被砸穿。
2. A、B、C 都相同，整条训练曲线应该相近（在相同条件 Cond 且有效步长 C3 调到同一尺度后）。

这套坐标的边界（做不到的地方）

  • 超参必须调到同一有效尺度（C3）。 DPO 系各种 loss 只有在 $\beta$ 和学习率调好之后才打平。没调好超参的比较，不能用来否定“同坐标等效”。
  • 不能把 `D1`（熵坍缩）当成不可证伪的“万能事后补丁”。 如果任何 C 层引起的上限差异都推给“因为熵变了”，规则 1 就会退化成套套逻辑。正确用法是事先标出 C 层导致崩塌的物理机制（Q-IV 失守、MoE 路由翻转、长度截断 $L_{\text{cap}} < T^*(x)$）。
  • 现有“同格打平”的公开实验多处于短程或小规模区间。 许多受控实验只跑了 200 步或短序列，短跑打平不等于 1000+ 步长思维链训练下不会因微小偏差累积而分叉。
问 3 · 用文献中已有的受控比较检验这套坐标

同格对照、异格对照、估计量族核对与矛盾案例记录

专项核对：“估计量族”（PG vs. DPO 闭式拟合 vs. 过滤 SFT）需要单独成轴吗？

把数据区间 B1 控制成一致之后，估计量族之间的差异远小于“离线 vs. 在线”的差异，但现有公开证据仍属于启发性假说而非最终定论：

  • Online DPO 与 GRPO / PPO： 在 Bridging Offline and Online RL (2506.21495) 中（Llama-3.1-8B-Instruct，注意：每个方法仅跑了 1 个训练 seed，未报告误差棒，且属于短/中程训练），Semi-Online DPO（$58.9$）和 Online DPO（$58.7$）在 MATH-500 上与 GRPO（$58.1$）表现接近，在 AlpacaEval LC 上甚至高于 GRPO；而 Offline DPO 在数学上落后三者 $4\text{–}5$ 分，在对话上落后超过 $20$ 分。同样，Ivison et al. (2406.09279) 在 Tulu 2 13B 上固定相同数据对比，PPO 领先 DPO 的平均幅度只有 $0.7$ 分（代码上为 $2.9$ 分）。不过，在 32k–64k 长思维链和大 $\mu$ 异步推理训练中，目前尚无受控实验证明 Online DPO 能复现 GRPO/PPO 的长程涌现。
  • 为什么仍有细微差别（而非无条件恒等）： 只有在每步都把参考模型重置为当前策略（$\pi_{\text{ref}} = \pi_{\theta_k},\, \mu=1$）且 $G=2$ 时，DPO 梯度前的权重 $\sigma(0)=1/2$ 才会在代数上退化为两样本 RLOO；实际使用的 Online DPO 通常保留固定或慢速更新的 $\pi_{\text{ref}}$（自带隐式 KL 约束），而 GRPO 用 $G>2$ 组基线且常设 $\beta=0$（属于 A4 与 C2 的区别）。
  • 过滤 SFT（只训正样本）与正负对比的区别： OLMo 3 (2512.13961)（单次运行）发现，用大模型回答优于小模型回答做 DPO 对比，效果好于只在正样本上做 SFT。这可以直接在 C1 坐标里刻画：过滤 SFT 等价于把负优势象限（$\hat A < 0$）置零，缺少主动压低高先验错误模式（如Kimi k1.5 所强调的负梯度）的能力。

3. 预测受挫、前后矛盾与暴露坐标边界的案例记录

如果只挑符合预期的实验，任何分类法都会显得“好得不像真的”。把文献里真正打架或暴露局限的案例单列出来，才能看清这套坐标的真实边界：

  • 案例 1 · Base 与 Instruct 模型上 A3 和 C1 结论同时反号（Tricks or Traps, 2508.08221）： 在 Qwen3-8B 上，Base 模型用 token-level 聚合更好、提高 $\varepsilon_{\text{high}}$ 没用或有害；到了 instruction-tuned 模型上，反而是 sequence-level 聚合更好、Clip-Higher 有益（4B 在 $0.32$、8B 在 $0.28$ 见顶）。这说明如果不以 Cond（$\pi_{\text{ref}}$ 的初始熵与长度分布）为条件，单看 A3 或 C1 无法预测正负号。
  • 案例 2 · ScaleRL 内部“前向消融”与“Leave-One-Out 消融”的四处自相矛盾（2510.13786）： 在弱基线上逐个加组件（前向消融）时，CISPO、零方差过滤、FP32 LM head 都显著抬高了拟合渐近线 $A$（例如 FP32 head 把 $A$ 从 $0.52$ 提到 $0.61$）；但在完整配方上做 LOO 时，去掉它们中的任何一个，$A$ 却都在 $\pm 0.02$ 噪声带内！原因在于多个组件修补的是同一个底层脆弱性（如 noisy ratio 导致的失稳），单独加时救活了训练（表现为 $A$ 升高），但在成熟配方里彼此冗余。而且后续研究（2610.04158）指出，在有限算力窗口内，没有渐近线的对数线性曲线与 sigmoid 拟合得几乎一样好——所谓“改变上限 $A$”很多时候只是稳定性差异的外推假象。
  • 案例 3 · 小模型短跑与 150B MoE 大规模运行在 Critic（C2）上的未解张力： GenAC（2604.10701）在 Qwen3-8B-Base 上训 200 步证明 VC-PPO 与 GRPO/RLOO 仅差 $0.5\text{–}0.9$ 分；但 Seed1.5-Thinking (2504.13914) 在 150B MoE 上报告带 critic 的 VAPO 为 $79$ vs. DAPO 的 $73$。8B 上的 200 步受控实验能拆穿“基线没配好导致的 10 分假差距”，但不能排除在超大模型或长程多轮任务中 critic 仍有独立价值。
  • 案例 4 · 随机/虚假奖励在 Qwen2.5-Math 上涨 $+21.4$ 分，在 Llama-3.1 上跌 $-11.5$ 分、在去污 OLMo 3 上为 $0$（2506.10947, 2507.10532, 2512.13961）： 证明当 Cond 中的 $\pi_{\text{ref}}$ 存在预训练污染（Qwen2.5-Math 在给前 $60\%$ 题目时能逐字背出 $54.6\%$ 的 MATH-500 文本，而 Llama 为 $3.8\%$）或高准确率的预设模式（Python 代码模式占 $65\%$ 且准确率 $60.9\%$）时，哪怕 A1 是 $0\text{-bit}$ 噪声，单靠 D1 降熵锐化也能刷出 20 分。
  • 案例 5 · 树分叉信用分配与 Token 掩码的混淆（SPO, 2505.23564）： SPO 的树结构信用分配在 $2\text{k}$ 长度下比 GRPO 高 $11.6$ 个 MATH-500 点，但在 $4\text{k}$ 降为 $7.6$ 点，到 $32\text{k}$ 仅差 $0.8$ 点（AIME24 打平）；且作者发现仅靠一个 token mask 就解释了其在 GSM8K 上的大部分增益。这提醒我们 `C2` 里的“精细信用分配”随着上下文放长和规模变大，收益会快速衰减。
问 4 · 从这套两层结构直接推出工程判断

三类改动的本质：修不动点偏差、维持离策略逼近、或未承认的目标改动

一个算法到底能改变什么

base model、奖励、数据、算力都固定时，RL 算法能影响的只有梯度估计的偏差、方差和训练的稳定性。逐项看：

  • 大多数 clip 变体在 on-policy 时完全不起作用。每批数据只更新一步、并且 $\pi_{\text{old}}$ 在训练端重算时，$r=\pi_\theta/\pi_{\text{old}}\equiv 1$，clip 不会被触发：
    $$\nabla_\theta\,\min\!\big(r\hat A,\ \mathrm{clip}(r,1\!-\!\epsilon,1\!+\!\epsilon)\,\hat A\big)\Big|_{r=1}=\hat A\,\nabla_\theta\log\pi_\theta$$
    这时 PPO-clip、DAPO、GSPO、CISPO、SAPO 的梯度完全一样，都是 REINFORCE，区别只剩归一化方式。它们只在数据被复用、或数据来自旧策略时才有区别。
  • baseline 只降方差，不改变期望梯度。group mean、leave-one-out、critic 的差别在 $O(1/G)$ 量级，group 一大就基本消失。critic 只有在 $\lambda<1$、真正参与 credit assignment 时才会改变结果，而这时它也会引入偏差。
  • 归一化改的是目标，不是估计质量。对一个通过率为 $p$ 的 prompt，除以组内 std 相当于把目标从 $\sum_x p_x$ 换成 $\sum_x F(p_x)$，其中
    $$F'(p)=\frac{1}{\sqrt{p(1-p)}},\qquad F(p)=2\arcsin\sqrt{p}$$
    它给 $p$ 接近 0 或 1 的题更大的权重。这会影响 pass@k 和哪些题能被学会，但对 pass@1 的上限影响有限。
  • 任何算法都创造不出 base model 没有的概率质量。最优解是对参考分布的指数倾斜，上限从根上就不在算法里（见上面演示中的 y9）。

受控实验的结论和这几条推导一致：

  • ScaleRL 的 leave-one-out：从完整 recipe 里去掉任何一个组件，渐近上限都在噪声范围内。
  • GenAC 只换 advantage 估计量，GRPO、RLOO、PPO 的差距约 1 分。
  • DPO 系的各种 loss 在 β 调好之后打平。
  • PRM 加进奖励之后会被模型钻空子。

所以这些算法分三类

有用，而且必须

修正确性的

长 CoT 下用 $\lambda=1$、MoE 用 routing replay、消除训练与推理的数值不一致、多轮任务里屏蔽环境 token、限制同一批数据的复用次数。它们不提高上限，但不做的话训练会悄悄偏掉，或者直接崩溃。

有条件地有用

在系统约束下换效率和稳定性的

CISPO、GSPO、TIS、IcePop 只有在系统逼你 off-policy 时才起作用：异步 rollout、MoE、低精度推理、一批数据更新十几步。很多算法创新其实是对 infra 约束的回应，这是算法和 infra 之间最实质的联系。

大多是噪声

“新 loss 带来更高分数”的

增益通常是单 seed、只在 Qwen 上测的 1 到 3 分，落在评测噪声以内。不少是拿没调好的 baseline 比出来的。

真正的杠杆在哪

能显著改变结果的都在估计量之外：

  • 信号质量：verifier 的精度、奖励能不能被钻空子。奖励有偏差，目标分布就跟着偏。
  • base model 和数据：它们决定支撑集，也就是 RL 最多能锐化出什么。
  • 算力怎么花：batch size 和生成长度是少数在受控实验里明确抬高上限的因素。
  • 还没被证明、但原理上可能变得重要的两件事：长程 agent 的 credit assignment（horizon 越长，只靠最终结果的奖励越不够用）；探索（怎么让模型采到原本采不到的正确答案）。

两处需要打折

  • 现有证据很薄。多数是单 seed、单一模型族、1.5B 到 8B 规模。有些效应可能只在前沿规模才显现，而前沿实验室的内部消融不公开。比如 DeepSeek 说 Keep Routing “至关重要”，但没给数据。
  • “没用”指的是不决定上限，不是不值得做。第一、二类在工程上往往是必要的。

小结：怎么用这套框架读任何一篇新 RL 论文

当一篇新算法论文出来时，不需要先给它打分，只需按三步检验：① 把它的更新式写成规范形式，读出它在 目标层（A1–A4）、运行区间（B1）、逼近层（C1–C3） 上的坐标；② 问一句“它改变不动点 $\pi^*$ 了吗，还是只在 B1 离策略条件下改了逼近路径或 D1 熵轨迹？”；③ 查表对照同格算法在受控条件下的已有实证。

问 5 · 跳出学术界单域数学刷榜，站在前沿后训练负责人（OpenAI / Anthropic 视角）看

从单次 RLVR 到工业级后训练系统：坐标表之外的五个真实战场

前面的两层坐标体系（A / B / C / D）把过去三年学术界在单域数学/代码 RLVR 与偏好对齐 Loss 上的混战梳理清楚了——对于“砍掉无效的新 Loss 复现、排查 MoE 与离策略基础设施隐患”，它是一套极好用的去噪工具。

但如果我们站在 OpenAI 或 Anthropic 这类前沿实验室后训练负责人的视角，就会发现学术论文（95% 是在 7B–32B 模型上跑 200–500 步单域数学题）与工业界主线之间存在一个巨大的代差：前沿后训练从来不是在单域 AIME 上刷 2 分，而是在同一个旗舰模型上同时对齐数学、竞赛代码、真实软件工程（SWE / 终端操作）、长文写作、深度研究以及安全边界（Safety / Honesty）。 在这个真实战场上，真正卡脖子的往往是下面五个坐标表尚未完全展开的深水区：

1. 多域混合 RL 的梯度干扰与“对齐税”（向量 $\vec{R}$，而非标量 $R$）

在单域论文里，A1 只是单一通道（要么是精确 0/1 验证器，要么是对话 RM），A2 只是同一题库内的难度权重 $F(p_x)$。但在工业界联合训练中，一个训练阶段往往混着异构环境：既有 32k 长度、0/1 稀疏反馈的数学与代码单元测试，又有 1k 长度、由神经网络 Rubric/RM 连续打分的写作、语气、指令遵循与安全拒答。

  • 为什么会打架：精确验证器的梯度方差形态、序列长度分布和最优步长，与软 RM 完全不在一个量级。长 CoT 的强化学习会迅速污染通用对话的文风（对简单闲聊也过度思考、机械列点、丧失文采），而通用对话 RM 的训练又会反过来削弱长程推理深度。
  • 工业界的真实解法：A2 的核心不再是单域内的 $F(p_x)$，而是跨环境的梯度范数配比、分域独立 KL 预算（$\beta_{\text{domain}}$）、显式思考预算条件化（Thinking-budget conditioning），或者走“先训分域 RL 专家 $\to$ 再通过 On-Policy Distillation（OPD）合流到单一通用基座”的架构。

2. 对抗性优化器下的环境与裁判工程（A1 占 80% 研发精力，C1 只占 5%）

在前沿团队里，80% 以上的研究人力花在构建环境与打分器（A1）上，只有不到 5% 花在调策略梯度截断（C1）上。在没有单元测试的真实任务（写完整 PR、深度网页调研、医疗/法律分析、复杂写作）中，根本不存在无偏的 0/1 Verifier。

  • 静态误差公式的局限：把代理奖励误差写成常数假阳性率 $\alpha_{\text{FP}}$ 低估了真实风险——因为 RL 策略是一个针对打分器做定向搜索的对抗优化器，随着 $\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})$ 增大，模型会主动搜出让裁判稳定误判的高分对抗样本（如固定讨好句式、伪造引用格式、空洞长文）。
  • 工业界怎么防 Hacking：不是靠单纯放大 $\beta$（那会直接锁死能力），而是靠结构化 Rubric 拆解（把主观好坏拆成可核对的原子判据）、成对生成式裁判（先写 Critique 再做 Pairwise 比较）、多 RM 悲观取小（$\min_k R_k$）、在奖励端显式回归正交化长度与格式偏置、以及在线迭代重训 RM（Iterative RM + Policy Co-evolution）。

3. 超长视界有状态 Agent（50–150 轮不可逆交互）vs. 单轮纯文本内省 CoT（C2 结论不能盲目外推）

基于 GenAC（~200 步单轮数学）和 SPO（32k 单轮数学），前文指出在单轮数学上“组均值（GRPO/RLOO）与带 Critic 的 PPO 上限持平、树分叉信用分配在 32k 长度下收益衰减到 $+0.8$ 分”。这个结论在单轮纯文本 CoT 上成立，因为模型可以通过上下文内的 "Wait, let me recheck" 自己完成回溯，不需要外部对中间 token 逐个归因；但绝不能外推到 50–150 轮的有状态外部环境 Agent（如 SWE-bench、Computer Use、多跳浏览器搜索）：

  • 成本与不可逆性：当一条轨迹包含 80 次容器内 bash 执行、耗时数十分钟、总长 100k tokens 时，环境状态转移昂贵且不可逆，不可能像单轮数学那样廉价地对同一题并发采 $G=64$ 条完整轨迹来算组均值。
  • 信噪比崩溃：到底是第 12 轮的搜索词选错了，还是第 65 轮的补丁写错了？只靠末尾一个 1-bit 结果把同一个 $\hat A_i$ 广播给 80 轮工具调用，信噪比几乎为零。在这个区间里，Turn 级价值基线（Critic）、环境状态检查点分叉（如 GiGPO 的状态分组）、以及高密度的步级环境反馈不再是“只改早期速度的可选项”，而是决定能不能学出来的必要条件。

4. 多代外循环飞轮：RL 与 OPD / 拒绝采样 SFT 是上下游接力，而非二选一

如果只看单次 RL 训练，模型确实受限于 $\operatorname{supp}(\pi_{\text{ref}})$，且一旦在训练后期发生 D1 熵坍缩就无法恢复。但前沿实验室从来不是一趟 RL 跑到底就上线，而是运行多代交替的外部飞轮（Outer Loop）：

$$\pi_{\text{ref}}^{(k)} \xrightarrow{\text{高温度 / Pass@}k\text{ 探索型 RL}} \text{采出高价值长链与工具轨迹} \xrightarrow{\text{OPD / 拒绝采样 SFT / 上下文蒸馏}} \pi_{\text{ref}}^{(k+1)}\text{（重置熵与基座）} \xrightarrow{\text{第 }k+1\text{ 代 RL}}$$
  • 打破单次训练的熵与支撑集死锁：在第 $k$ 代可以用极小甚至为 $0$ 的 $\beta$、配合高温度或 pass@k 加权去激进搜出难样本的解；一旦采到正确轨迹（哪怕过程啰嗦或策略熵已跌穿），立刻通过 On-Policy Distillation（OPD）或过滤 SFT 将其蒸馏回一个高熵、干净的新起点 $\pi_{\text{ref}}^{(k+1)}$（或并入 Mid-training 数据）。
  • RL 与 OPD 的真实分工：在坐标表里，OPD 看似只是 A1 里的另一种信号；但在系统层面，RL 是“用推理算力在前沿探路的生成器（Producer）”，而 OPD 是“把探路成果无损、低成本压回主模型的压缩器（Consumer）”。

5. 随通过率分布 $P_k(p_x)$ 相变演化的动态算力分配（把静态 Cond 变成动态控盘变量）

坐标表把 Cond（数据难度分布 $P(p_x)$、group size $G$、batch size $B$）当作静态前提，但对后训练负责人来说，随训练进程动态调度算力本身就是核心算法：

  • 训练前中后期的相变：训练初期，大量题目处在 $p_x \in [0.2, 0.8]$ 的高方差甜点区，$G=8$ 就能拿到很高的有效梯度占比（D2）。但到了训练中后期，$P_k(p_x)$ 会两极分化——90% 的题已经 $p_x \to 1$，剩下的硬骨头 $p_x < 0.01$。此时如果还死守固定的 $G=8$，几乎所有 group 都是全对或全错（$\hat A \equiv 0$），有效样本率 D2 跌向 $0$，算力全在空转。
  • 算力最优控盘：必须根据当前策略的通过率在线调整资源——把 $p_x \to 1$ 的已掌握题目移出活跃采样池（只留极小比例防遗忘），把省下的 rollout 算力按 $G(x) \propto 1/\hat p_x$ 动态集中到 $p_x \ll 0.1$ 的前沿难题上；而当某类难题在放大 $G$ 后依然 $\hat p_x \equiv 0$（撞上 y9 支撑集墙）时，果断停止追加 RL 算力，转而通过合成数据或专家示范回补 Mid-training / SFT。
